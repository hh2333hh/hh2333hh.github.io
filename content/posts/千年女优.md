《千年女优》是今敏执导的日本动画长片，由今敏与村井贞之共同编剧，平泽进配乐。[^film]影片讲述了传奇女优（即女演员）藤原千代子曲折的一生。而这一切，都要从一把钥匙说起。

## 关于钥匙的约定

年事已高的千代子早已息影，住在山里。前来拍摄纪录片的立花源也是她多年的影迷，他带来一把旧钥匙。千代子认出它，慢慢开始讲述自己年轻时的回忆。

{{< figure src="/images/posts/千年女优/the-key-close-up.webp" alt="黑色盒子里的旧钥匙，画面切到低头端详它的老年千代子" caption="立花把一把旧钥匙带到了千代子面前。" width="640" >}}

时值上世纪三四十年代，日本正深陷军国主义狂热。尽管如此，千代子却并未受到多少影响，她看重少女杂志，幻想和白马王子的邂逅。那是一个下雪的日子，还是学生的千代子撞见一位被追捕的左翼画家，帮他藏匿起来。画家告诉千代子，如今靠画具和笔恐怕难有作为，自己要前往满洲加入伙伴反抗政府的斗争。

千代子看到画家颈上挂的钥匙，他解释说它能打开自己最珍贵的东西，并让千代子猜猜看是什么。为了还能与画家相见，千代子想留到第二天再猜。可等她再来时，画家已经走了，她在雪里拾到了那把钥匙。为了追寻画家，千代子答应了电影公司的邀请，前往满洲拍摄。

{{< figure src="/images/posts/千年女优/the-painters-key.webp" alt="画家低头让千代子看他颈上挂的钥匙" caption="画家说，这把钥匙能打开他最珍贵的东西。" width="640" >}}

## 交错的影像与人生

遇见画家之前，银映电影公司的人就来找过千代子，当时的她对此没什么想法。而她的母亲觉得，这孩子这么怕羞，怎么看也不像做演员的料。

{{< figure src="/images/posts/千年女优/the-film-invitation.webp" alt="面对电影公司的邀请，母亲说身旁的千代子太怕羞，做不了演员" caption="银映上门邀千代子演戏，母亲觉得她太怕羞了。" width="640" >}}

但既然画家要去满洲，她便又答应出演，想借拍电影的机会去找他。讲到与画家分别的回忆，画面回到雪夜的车站。千代子沿着月台追赶列车，最后摔在雪里，眼看着车开远。

{{< figure src="/images/posts/千年女优/chasing-the-train.webp" alt="雪花飘过车窗，千代子沿着月台追赶列车" caption="千代子追着远去的列车。" width="640" >}}

镜头一转，拍摄纪录片的摄影师井田举着摄像机站在同一个月台上。原来刚才看见的已经是千代子演过的戏，可回头一想，竟说不清是从哪一刻换过去的。

{{< figure src="/images/posts/千年女优/when-did-it-become-a-film.webp" alt="井田转向立花发问，千代子还伏在他们身前的月台上" caption="「什么时候开始说电影的事了？」" width="640" >}}

从这座月台开始，千代子出演的电影与她的人生开始交错。

## 跨越千年的追寻

在被回忆起的千代子出演的一部影片里，她所饰演的古代公主遇到一位坐在纺车旁的老妇。老妇递来一杯茶，诅咒她从此受恋火焚烧，永远不得解脱。那本是戏中的一句话，往后看，却像也落在了千代子自己身上。

{{< figure src="/images/posts/千年女优/the-curse.webp" alt="千代子所饰的白衣女子面对烟雾中的老妇，字幕写着恋火焚身的诅咒" caption="老妇诅咒她永远受恋火焚烧。" width="640" >}}

千代子没有在满洲找到画家，但她的追寻却在电影里继续，跨越千年。她骑着白马越过原野，幕末的硝烟叠成了水面上的红日。转眼她已穿着洋装，撑伞坐在樱花下的马车里。红色列车从她身后驶过，转动的车轮里又叠出了穿和服、撑纸伞的她。背景的变化暗示日本从古代到明治再到大正的时代变迁。

{{< figure src="/images/posts/千年女优/across-the-eras.webp" alt="千代子骑白马穿过战场，炮烟叠成红日，随后马车、列车与撑纸伞的千代子接连出现" caption="时代换了几回，画面一直往前走（42:27–43:00）。" width="576" >}}

电影中变化的时代未曾改变千代子奔跑追寻的人生主题。在镜头里，她跑过一片树林，身上的衣服已经变了。再跑几步，她又穿着另一身戏服，迎面跑过来。那些本来要用许多话交代的年月，就从她的脚步里过去了。

{{< figure src="/images/posts/千年女优/running-through-the-films.webp" alt="千代子一路奔跑，树林、雪景和街道在她身后切换，她也换上不同年代的衣服" caption="衣服和布景一换，千代子的脚步还接得上。" width="640" >}}

## 无法填补的空缺

回到现实，战争已经接近尾声，日本本土开始遭受美军无休止的轰炸。在一次轰炸过后，千代子在废墟里找到画家留下的一幅画像。断墙上画的是少女时的她。许多年过去，她终于又看到了那个人留下的东西。

{{< figure src="/images/posts/千年女优/portrait-in-the-ruins.webp" alt="千代子抬头看见断墙上少女时期的自己，四周是轰炸后的废墟" caption="画家把少女千代子的画像留在了墙上。" width="640" >}}

后来，机缘巧合下千代子得到了画家留给她的信。这封迟来的信把千代子引向北海道。她一个人跑过茫茫的雪原。白茫茫空无一物的背景，暗示了千代子的追寻终究只是徒劳。

{{< figure src="/images/posts/千年女优/running-in-hokkaido.webp" alt="穿灰色大衣的千代子独自在深雪中奔跑，镜头切到她喘息的脸" caption="千代子在北海道的雪原上寻找画家。" width="640" >}}

雪地接上了她演过的电影。她穿着宇航服走到月面上的一幅画前，画家站在画中的雪地里，朝她抬起手。她开口叫他，画上的人影却慢慢淡去了。

{{< figure src="/images/posts/千年女优/the-painter-fades.webp" alt="画家站在画中的雪地上，身影逐渐淡去，只留下一串脚印" caption="画家从画布上消失，雪地里只剩一串脚印。" width="640" >}}

直到采访的尾声，观众才知道，画家早在被捕后就遭拷问杀害。当年追捕他的人亲口向立花承认了这件事，立花始终没有告诉千代子。她一直追寻的人，就像画上那串脚印的尽头，成了一个永远无法填补的空位。

## 永不停息的爱

这样看来，似乎这场贯穿千代子一生的追寻，从开始就是一场悲剧。但片尾千代子的独白，给出了一个截然不同的答案：她喜欢那个一直追寻着他的自己。

{{< figure src="/images/posts/千年女优/the-self-that-pursues.webp" alt="飞船里的年轻千代子说，她喜欢追寻着那个人的自己" caption="「因为我喜欢追寻着那个人的自己。」" width="640" >}}

援引一则 B 站评论，我们可以借拉康的欲望辩证法来解读这样一种追寻中展现的生命态度。

> 《千年女优》的故事，看似是一场“一生追逐一个早已死去的人”的悲剧，实则是通过欲望辩证法，完成了对主体存在的终极解放。
>
> 拉康的欲望辩证法，从来不是教我们如何“满足欲望”，而是教我们如何“承担欲望”。传统的叙事总是告诉我们，欲望的满足是幸福的终点，而拉康却揭示：一旦欲望被满足，它就会立刻消亡，主体会重新陷入存在的空洞之中。而千代子的伟大之处，就在于她用一生的时间，主动承担了欲望的永恒匮乏，她没有等待欲望的满足，而是让欲望的运动本身，成为了自己生命的全部意义。
>
> 键之君是永恒的空位，巡捕是永恒的阻碍，而千代子是永恒的追逐者——这三者构成的欲望辩证法，最终指向了一个最根本的存在命题：人不是先有了自我，才去追逐欲望；而是在永恒的欲望追逐中，才生成了独一无二的自我。千代子跨越千年的奔跑，最终不是为了抵达任何地方，而是为了成为那个永远在路上的、永远燃烧着的自己。

我也想到韩炳哲在《爱欲之死》里谈到的往复。爱让人走出原来的自己，又经由他者重新找到自己。他借费奇诺的话，把这写成一次死亡和重生。[^eros]今敏把这层往复拍进了一个叠化。病床上的千代子变成了飞船里的年轻人。死亡已近在眼前，她却又要出发了。
